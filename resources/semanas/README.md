# Guías semana a semana

Cada guía es el paso a paso de una semana del [roadmap](../applied-ai-engineering-roadmap.md). Todas siguen la misma estructura:

1. **Objetivo** y tabla con el reparto por días.
2. **📖 Qué vas a aprender:** los conceptos, explicados antes de tocar código.
3. **Días:** pasos numerados con el código base, los comandos y **"Está bien si…"** para comprobar cada paso.
4. **Lo escribes tú:** en cada semana hay una pieza central que programas tú, con su especificación, sus tests y la solución escondida en un desplegable (ábrela solo si llevas un rato atascado).
5. **Algoritmos y carrera:** los problemas con sus pruebas y pistas, y las tareas de candidaturas y networking.
6. **Cierre del domingo**, **checklist** y **🆘 Si te atascas** con los errores más comunes.

> Las librerías de IA (LangGraph, Langfuse, MCP, la API de Gemini) cambian rápido. Si un import o un nombre de modelo no funciona, busca el equivalente en su documentación oficial o pregúntale a Claude Code. La idea de cada paso sigue valiendo.
